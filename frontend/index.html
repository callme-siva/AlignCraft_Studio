💡 Why Fine-Tune Small Models (SLMs) & Red-Team Them?
The Power of QLoRA (Topic 7)
  • Ultra-low VRAM: Trains 1B–3B parameter models on a single consumer GPU or Apple Silicon laptop.
  • 100% Schema Precision: Fine-tuning directly teaches the model token transition probabilities for valid JSON with zero conversational fluff.
  • Edge Deployment: Exports straight to Ollama/GGUF to run on-device with zero external API fees.
The Necessity of Evals & Red-Teaming (Topic 8)
  • Adversarial Immunity: Base models easily fall for "DAN mode" and simulated developer bypasses. Red-teaming proves your alignment worked.
  • Automated Regression Testing: Run automated suites before merging model weights to prevent catastrophic forgetting.
  • Objective Rubric Scoring: LLM-as-a-Judge provides automated, calibrated scoring on complex qualitative outputs.
